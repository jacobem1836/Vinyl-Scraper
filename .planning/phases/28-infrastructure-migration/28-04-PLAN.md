  <action>
Create `.github/workflows/deploy.yml` with these EXACT contents:

```yaml
name: Deploy to Fly.io

on:
  push:
    branches:
      - main
  workflow_dispatch:

concurrency:
  group: deploy-${{ github.ref }}
  cancel-in-progress: true

jobs:
  deploy:
    name: Deploy app
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup flyctl
        uses: superfly/flyctl-actions/setup-flyctl@master

      - name: Deploy to Fly.io
        run: flyctl deploy --remote-only
        env:
          FLY_API_TOKEN: ${{ secrets.FLY_API_TOKEN }}
```

Notes:
- `--remote-only` builds on Fly's builders (no Docker needed in CI), faster and avoids local-builder differences
- `concurrency` block prevents overlapping deploys on rapid pushes
- `workflow_dispatch` lets you trigger a manual redeploy from the Actions tab without a commit
- `superfly/flyctl-actions/setup-flyctl@master` is the official action per D-03 in CONTEXT (note: the org rebranded from `fly-apps` to `superfly` — `superfly/flyctl-actions` is the current canonical path)

Create the directory first if needed: `mkdir -p .github/workflows`.
